## Sebelum mulai UI



Sebelum masuk **Stage 06.2 (Motion Design Foundation)**, saya menyarankan membuat **Stage 06.1 — AI Engineering Context** terlebih dahulu. Di tahap ini AI Agent diminta menyusun `AGENTS.md` berdasarkan seluruh fondasi proyek yang sudah selesai: arsitektur folder (`app/`, `modules/`, `common/`, `services/`, `hooks/`, `contents/`, `types/`, `lib/`, `styles/`), stack teknologi (Next.js App Router, TypeScript strict, Tailwind CSS v4, shadcn/ui, MongoDB Atlas, Auth.js v5), aturan mobile-first, design system (tema Zinc Neutral untuk light mode dan Porcelain White untuk dark mode dengan aksen Marine Deep dan Obsidian Violet), serta prinsip SOLID, DRY, KISS, Server Components secara default, dan validasi lint/typecheck/build.



Dengan begitu, setiap AI coding agent yang kamu gunakan nantinya—baik Gemini CLI, Claude Code, Roo Code, Codex CLI, atau yang lain—akan memiliki konteks proyek yang sama dan menghasilkan implementasi yang konsisten sejak awal hingga tahap production.
